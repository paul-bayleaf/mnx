The multi-staff placement object

Type: String

Represents a symbol's vertical placement, with respect to one or more staves, including support for multi-staff music via the "between" value. See also placement, which doesn't support "between".

Allowed values:

Value Description
"above"
"auto" Consuming applications are free to use their own algorithms to determine placement.
"below"
"between" Between multiple staves of music. For example: between the two staves in a grand staff.

Parent objects

This object is used by the following parent objects:

  • accent dynamic: "placement"
  • gradual dynamic: "placement"
  • immediate dynamic: "placement"
  • measure repeat counter: "placement"
  • relative dynamic: "placement"
